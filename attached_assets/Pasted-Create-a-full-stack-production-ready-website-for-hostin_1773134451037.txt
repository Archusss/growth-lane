Create a full-stack production-ready website for hosting free downloadable ebooks.

GENERAL REQUIREMENTS

The website must be fully functional without relying on third-party authentication systems.

All authentication, logging, and admin permissions must be handled within the site's own backend.

The system must store all data in a database controlled by the site.

The website must be easy to edit later to add new ebooks.

TECH STACK Use:

Next.js frontend

Node.js backend

PostgreSQL database

TailwindCSS for styling

Pages:

Admin Dashboard (protected route)

LOGIN SYSTEM

Create a secure login system using hashed passwords

Use JWT or session authentication

No public signup page

Only admin login exists

Login page must not appear in navigation

Login page should only be accessible via a direct URL

ADMIN DASHBOARD This page must only be visible if the logged-in user is an admin.

Features:

View analytics

Add new ebook entries
